## 1. 一句話介紹

一款**畫面超寫實**的第一人稱開放世界合作遊戲。這個世界是一款**沒做完的爛遊戲**：開發者把好幾款不同類型的遊戲縫在一起之後就跑路了。玩家可以建造、打仗、種田、釣魚、開車、練等級，用自己喜歡的方式活下去並通關。

## 2. 核心設計原則

1. **讓人想問「這到底是什麼鬼」**，但荒謬必須**有邏輯**：規則固定，玩家能推理、能實驗，偶爾加一點完全沒道理的隨機事件當調味。
2. **系統之間合理配合**，不亂變。釣的魚能吃、能當飼料；農作物能做燃料；載具用來運貨；槍用來打獵。荒謬感不靠「魚變成槍」這種亂接。
3. **每個系統都做深**，讓玩家有不同玩法。
4. **每種玩法都能通關，也能互相混用**。只想種田的玩家可以完全不打仗就通關主線。

### 抽象感的四個來源

| 來源 | 說明 |
|---|---|
| 縫合痕跡看得到 | 畫面全寫實，但每個遊戲區的 HUD、音樂、對話框、小地圖、規則都像來自不同遊戲 |
| 世界和劇情很怪 | 空白沒做完的區域、佔位模型、bug、會抱怨開發者的 NPC |
| 組合出乎意料 | 系統邏輯都合理，但玩家能組出很瞎的東西（把農場蓋在卡車上、開船拖網捕魚） |
| 寫實物理的荒謬 | 一切照寫實物理運作，自然產生鬧劇（類似《模擬山羊》、Teardown） |

## 3. 基本規格

| 項目 | 決定 |

| 平台 | PC |

## 4. 世界觀與主線

### 世界觀：開發者跑路了

這個世界是一款沒做完的遊戲。開發者把好幾款不同類型遊戲的程式碼縫在一起之後就消失了。

### 主線（三段串接）

1. **想逃出去**：玩家發現自己困在一款爛遊戲裡，想找到離開的方法
2. **要找開發者**：發現只有開發者能放你出去，開始追查他的下落（散落各地的筆記、commit 訊息、未完成的區域）
3. **只能自己把遊戲做完**：最後發現唯一的出路是自己接手，把這款遊戲做完

通關後世界繼續開放，可以自由玩。

> 待討論：開發者是誰、為什麼跑路、各段劇情細節、重要 NPC、結局。

## 5. 開局選角

開角色時選擇身分，每個身分有不同開場、起始配備和成長曲線。之後新增遊戲區時，會跟著新增對應的身分。

| 身分 | 來歷 | 機制 |
|---|---|---|
| **預設角色** | 開發者沒刪掉的測試模板，檔名叫 `Character_Default_FINAL_v2` | 沒有任何加成。NPC 偶爾把你當成沒做完的模型 |
| **射擊遊戲難民** | 從軍事射擊遊戲跑過來的大兵，習慣了「躲牆後自動回血」 | 開局送隨機槍械；槍械、農場技能升得很快；受到的傷害提高（這裡沒有自動回血）；吃軍糧或能量飲料有隨機 BUFF |
| **被封鎖的外掛玩家** | 在別款遊戲開外掛被封，結果被丟進這款爛遊戲 | 自帶外掛（ESP、自瞄）；技能升得慢（系統一直懷疑你作弊）；FOV 被外掛寫死不能調；開局武器是機械鍵盤；吃泡麵有隨機 BUFF |

> 設計想法：外掛玩家的 ESP 可以當主線工具，例如看見開發者留下的隱藏訊息。

## 6. 世界

- **程式生成**的寫實平滑地形（不是方塊）
- 世界由多個**遊戲區**拼成，每區來自一款「不同的遊戲」
- **全開放**：一開始就能去任何區，越遠越難（類似《薩爾達：曠野之息》），主線線索分散在各區，順序自由
- 區與區的交界處看得到縫合痕跡：地形硬切、天氣突變、HUD 切換
- 遊戲區要**模組化**，之後持續擴充新區時不用改舊程式

### 第一批遊戲區

| 遊戲區 | 來源類型 | 特色 |
|---|---|---|
| 生存荒野 | 生存遊戲 | 原始森林、野生動物，木材和石頭的產地 |
| 鄉村農場 | 農場模擬 | 田地、牧場、小鎮、友善到可疑的村民 |
| 軍事戰區 | 軍事射擊 | 廢棄城鎮、基地、巡邏部隊，金屬、槍械、軍用載具的來源 |
| 賽車都市 | 開放世界賽車 | 高速公路、霓虹城市、街頭賽車、改裝廠，水泥和玻璃的產地 |

### 依遊戲區而定的規則

| 規則 | 生存荒野 | 鄉村農場 | 軍事戰區 | 賽車都市 |
|---|---|---|---|---|
| 死亡懲罰 | 掉光物品，要回去撿 | 暈倒被送回家、扣錢 | 在重生點重生 | 「重新開始比賽」 |
| 基地威脅 | 野獸夜間來襲 | 偶發事件（如颱風） | 巡邏部隊攻擊 | 警察或幫派上門 |
| 彈藥 | 稀缺，只能自己做 | （待定） | 充足 | 用買的 |

## 7. 系統

### 7.1 建造

- **擺放**：每個物件都能切換**吸附拼接**或**自由擺放**
- **結構物理**：有支撐計算，沒支撐會倒；可以被槍、車、爆炸破壞，並寫實崩塌
- **地形改造**：能挖能填（整地、挖溝、挖池塘、堆山坡），挖到一定深度碰到岩床
- **材料分級**：木 → 石 → 金屬 → 水泥 → 高科技，越高級越堅固；不同材料出在不同遊戲區，促使玩家跨區
- **功能建築**：
  - 工作台與設施（工作台、熔爐、槍械改裝台、車庫、穀倉、魚塘）
  - 電力與線路（發電機、太陽能、電線，接燈、電門、自動灑水）
  - 自動化產線（輸送帶、機械臂、自動收成和加工）
  - 機關與防禦（自動砲台、陷阱、彈射板、可動關節）
- **移動建築**：可以蓋在大型載具上，也能用建造系統從零組裝載具（見 7.2）
- **藍圖**：組好的東西可以存成藍圖，用材料一鍵重建，也能分享給朋友

### 7.2 載具

- **類型**：腳踏車、滑板；陸地（汽車、機車、卡車、坦克、拖拉機、火車）；水上與水下（小船、快艇、漁船、潛水艇）；空中（直升機、飛機、熱氣球、滑翔翼）；騎乘動物（馬、牛、駱駝）
- **手感**：街機手感，好開、容易甩尾（類似 GTA）
- **損壞**：外觀會變形、零件會掉；引擎、輪胎、油箱各自有血量，壞了會影響駕駛，可以維修
- **取得**：從零組裝、在世界中找到、購買、藍圖複製
- **多人合作**：
  - 多座位分工（駕駛、砲手、維修、導航）
  - 在大型載具上可以自由走動、做事（釣魚、種田、開槍）
  - 乘客可以開槍，載具也能裝固定武器
  - 拖曳與連結（繩索、拖車鉤）
- **維護**：要燃料也要維修，並和其他系統連動。燃料有汽油、電力、生質燃料（用農作物做）；汽油可從戰區或都市取得，也能自己蓋煉油產線。騎乘動物要吃飼料、會累

### 7.3 槍械與戰鬥

- **槍感**：半寫實，有後座力、彈道下墜、換彈時間，但好上手（類似《決勝時刻》、Battlefield）
- **改裝**：配件槽位式（瞄具、槍管、彈匣、槍托、握把），每個配件改變數值
- **取得**：自己製作（從土槍到高科技，可接自動化產線）、戰區搜刮、購買、任務獎勵
- **敵人**：
  - 野生動物（同時也是打獵資源）
  - 人類敵對勢力（戰區軍隊、都市幫派、荒野盜匪），具小隊戰術 AI
  - 「縫合失敗」的怪物（佔位模型、模型錯亂的生物、會穿牆的 bug 怪），主線的主要敵人
  - 各遊戲區的 Boss，照它來源遊戲的規則打
- **其他戰鬥手段**：
  - 近戰武器（刀、斧、鍋子、機械鍵盤，農具和工具也能當武器）
  - 投擲與爆裂物（手榴彈、燃燒彈、C4；任何物品都能丟，有物理傷害）
  - 非戰鬥解法（潛行、用食物馴服野獸、開車衝過去、蓋牆擋住、談判或賄賂）
  - 夥伴與養的動物幫打
- **友軍傷害**：房主開世界時自選，預設開啟、傷害減半
- **彈藥**：稀缺程度依遊戲區而定

### 7.4 養殖

- **農作物**：有適合的季節和氣候；土壤有肥力，連續種同一種會變差；灑水、施肥會影響收成品質
- **動物**：餵食、清潔、好感度會影響產出；可以配種，後代繼承屬性（速度、體力、產量）。養出最快的馬當坐騎、最強的狗當夥伴
- **馴服**：野生動物（狼、熊、野馬等）可以馴服、帶回家繁殖；「縫合失敗」的怪物和 Boss 不行
- **料理**：食材照食譜做成料理，不同料理給不同 BUFF（射擊穩定、釣魚運氣、駕駛加速）。食譜要探索或實驗才會發現，品質越高 BUFF 越強
- **多人**：農場、動物、倉庫全隊共用

### 7.5 釣魚

- **操作**：拋竿、等待、咬鉤都是寫實物理和畫面；中魚後跳出一個風格不搭的拉魚小遊戲（縫合痕跡）
- **其他捕魚方式**：
  - 漁網與陷阱（漁籠、撒網、開船拖網，可接自動化）
  - 潛水魚槍（可接槍械改裝系統）
  - 特殊水域（冰釣、岩漿釣、在「沒做完的空白區」釣出開發者遺物，可推進主線）
  - 魚塘養殖（繁殖稀有魚種，使用養殖的遺傳系統）
- **收集**：每種魚有出現的地點、時段、天氣、魚餌；有尺寸和重量紀錄、傳說魚；收集圖鑑有獎勵
- **裝備**：釣竿和魚餌依一般方式分等級升級

### 7.6 RPG

- **成長方式**：用什麼升什麼（類似《上古卷軸》），沒有職業限制
- **技能分類**：每個系統一個大技能，底下有子技能
  - 例：建造、槍械（手槍、步槍、狙擊…）、養殖、釣魚、駕駛、生存
  - 升級解鎖被動效果和新配方
- **NPC 與任務**：主線和重要支線手寫、有劇情；各區 NPC 會發程式生成的日常任務（送貨、獵殺、蓋東西、釣特定的魚）
- **經濟**：全世界通用一種貨幣
- **生存需求**：所有遊戲區都有飢餓和口渴

## 8. 技術方向（初步）

- **語言**：以 C++ 撰寫遊戲邏輯，Blueprint 只用在必要的編輯器接線
- **多人架構**：從第一天就照 UE5 的 Replication 架構寫，所有系統（釣魚、槍械、載具、建造、養殖）都要能同步
- **遊戲區模組化**：每個遊戲區的規則（死亡、HUD 風格、威脅、彈藥、音樂）用資料驅動的設定描述，新增遊戲區不用改核心程式
- **開發流程**：程式碼在 GitHub 上維護；在本機以 UE5 編譯、測試，回報問題後再修改
